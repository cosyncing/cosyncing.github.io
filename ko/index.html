어디서나 동기화.

에이전트를 동기화하세요. CLI에서 GUI로, 데스크톱에서 휴대폰으로.

어디에 있든 멈춘 지점에서 그대로 이어가세요. cosyncing은 여러분의 네트워크 안에서 코딩 에이전트를 계속 동기화합니다.

다운로드

서버를 설치하고, 클라이언트를 받으세요

사전 요구 사항: 모든 기기에 Tailscale, 서버에 Bun 1.3.8 이상과 npm. 사용량 추적에는 Tokdash를 강력히 권장합니다. 자세한 내용은 사전 요구 사항 전체를 참고하세요. 

# Tailscale 로그인 완료, Bun 1.3.8 이상과 Node.js/npm 설치됨
$ npm install --global cosyncing
$ cosyncing setup
# 설정 후에는 cosy가 cosyncing의 축약형
$ cosy pair

그다음 사용할 기기마다 클라이언트를 받으세요. Windows, macOS, Linux, Android 빌드는 GitHub Releases에 공개되어 있습니다.

클라이언트

같은 세션, 같은 수신함, 같은 제어권 이전. 소스 트리와 CI는 Android, iOS, Linux, macOS, Windows, 웹의 여섯 가지 클라이언트를 다룹니다. Android와 데스크톱 클라이언트 빌드는 GitHub Releases에서 받을 수 있고, iOS는 이후 TestFlight로 제공할 예정입니다.

언제나 동기화

에이전트는 계속 일하고, 모든 화면이 그 속도를 따라갑니다.

에이전트가 쓰는 순간 한 줄씩 앱에 도착합니다. 어떤 기기에서 프롬프트를 보내도 터미널과 앱의 내용이 어긋나지 않습니다.

cosyncing 앱  ⇸  에이전트 CLI — 실시간

하나의 프로토콜, 여섯 에이전트
기능

모든 세션을 손 닿는 곳에

서버는 에이전트가 이미 실행 중인 곳에서 이들을 지켜보고, 각 세션을 보여 주는 클라이언트를 제공합니다. 세션은 프로젝트별로 묶여 대화 기록, 변경 내용, 명령, 질문과 함께 표시됩니다.

모든 프로젝트를 한곳에

모든 에이전트를 지휘하세요. 작업 중, 입력 필요, 대기 중 상태를 한눈에 봅니다. 세션을 열면 대화 기록을 읽고, 변경 내용을 확인하고, 도구 호출을 실시간으로 따라갈 수 있습니다.

알림 수신함

권한 요청, 에이전트의 질문, 완료된 실행이 여러 서버를 아우르는 하나의 수신함에 모입니다.

진짜 동기화

터미널이 돌아가는 동안에도 앱에서 프롬프트를 보낼 수 있습니다. Codex, OpenCode, Pi에서는 양쪽이 완전히 발을 맞춥니다. Claude Code 세션은 제어권을 가져오기 전까지 읽기 전용입니다.

명시적인 페어링

기기 접근 권한은 5분간 유효한 일회용 QR 코드로 부여합니다. 목록 확인과 해지는 CLI에서 합니다.

예약 메시지

정해진 시각에 도착하도록 프롬프트를 예약하세요. 에이전트가 일정에 맞춰 받아 갑니다.

작동 방식

세 단계, 계정 없이

1

서버 실행하기

cosyncing setup은 무엇을 바꿀지 정확히 보여 준 뒤, 계획 전체를 적용하거나 아무것도 적용하지 않습니다.

2

기기 페어링하기

cosyncing pair가 일회용 QR 코드를 표시합니다. 어떤 클라이언트에서든 스캔하면 그 기기에 접근을 허용합니다.

3

계속 나아가기

질문에 답하고, 대화 기록을 읽고, 제어권을 가져오세요. 여러분의 네트워크에 있는 브라우저, 휴대폰, 데스크톱 어디서든 됩니다.

개인정보와 보안

여러분의 컴퓨터. 여러분의 네트워크. 여러분의 데이터.

서버 상태는 서버를 실행하는 컴퓨터에 그대로 남습니다. 세션 내용은 여러분이 선택한 네트워크를 통해 인증된 클라이언트에만 전송됩니다.

중계 서비스 없음

연결 경로에 cosyncing이 운영하는 서비스는 없습니다. 분석이나 광고 텔레메트리도 없습니다. 선택 연동 기능은 여러분이 고른 서비스에만 접속합니다.

언제든 해지 가능

cosyncing devices list로 페어링된 기기를 확인하고, devices revoke <id>로 하나를 해지합니다.

질문을 놓치지 않도록

모든 질문을 하나의 수신함에

에이전트가 여러분을 필요로 하면 알림 수신함에 도착합니다. 그때 손에 있는 기기로 답하세요.

  • 권한 요청 은 명령의 전체 맥락과 함께 도착합니다. 한 번 눌러 승인하거나 닫으세요.
  • 에이전트의 질문 은 세션을 연결된 상태로 두므로, 답변이 에이전트가 기다리는 곳에 도착합니다.
  • 완료된 실행 — 긴 작업은 기다릴 때만이 아니라 끝났을 때도 알려 줍니다.
  • 여러 서버 지원 — 페어링된 모든 서버가 같은 목록으로 보고합니다.
