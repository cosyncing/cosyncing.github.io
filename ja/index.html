どこでもコーディング。
どこでも同期。

エージェントを同期する。CLI から GUI へ、デスクトップから携帯へ。

どこにいても、中断したところから再開できます。cosyncing は自分のネットワークの中で コーディングエージェントを同期させ続けます。

ダウンロード

サーバーを入れて、クライアントを入手

前提条件: すべての端末に Tailscale、サーバーに Bun 1.3.8 以降と npm。使用量の把握には Tokdash を強くおすすめします。 詳しくは前提条件の一覧をご覧ください。 

# Tailscale にサインイン済み、Bun 1.3.8 以降と Node.js/npm を導入済み
$ npm install --global cosyncing
$ cosyncing setup
# セットアップ後は cosy が cosyncing の短縮形
$ cosy pair

あとは使いたい端末ごとにクライアントを入手するだけです。Windows、macOS、Linux、Android の ビルドは GitHub Releases で公開しています。

いつでも同期

エージェントが書いた瞬間に、一行ずつアプリへ届きます。どの端末からプロンプトを送っても、 ターミナルとアプリの内容が食い違うことはありません。

1 つのプロトコル、6 つのエージェント
機能

すべてのセッションに、すぐ手が届く

サーバーは、エージェントがすでに動いている場所でそれらを監視し、各セッションを表示するクライアントを提供します。セッションはプロジェクトごとにまとまり、トランスクリプト、差分、コマンド、質問がそのまま見えます。

すべてのプロジェクトを 1 か所で

すべてのエージェントの指揮を執れます。作業中、入力待ち、待機中の状態がひと目で分かります。セッションを開けば、トランスクリプトを読み、差分を確認し、ツール呼び出しをリアルタイムで追えます。

通知の受信箱

権限リクエスト、エージェントからの質問、完了した実行が、複数サーバー共通の 1 つの受信箱に届きます。

本物の同期

ターミナルを動かしたままアプリからプロンプトを送れます。Codex、OpenCode、Pi では両側が完全に足並みをそろえます。Claude Code のセッションは、引き継ぐまで読み取り専用です。

明示的なペアリング

端末へのアクセス許可は、5 分間有効・1 回限りの QR コードで行います。一覧表示と失効は CLI から。

メッセージの予約送信

指定した時刻に届くようプロンプトを予約できます。エージェントは予定どおりに受け取ります。

仕組み

3 ステップ、アカウント不要

1

サーバーを動かす

cosyncing setup は何を変更するかを正確に示し、計画全体を適用するか、まったく適用しないかのどちらかを行います。

2

端末をペアリングする

cosyncing pair が使い切りの QR コードを表示します。どのクライアントからでも読み取れば、その端末にアクセスを許可できます。

3

そのまま進む

質問に答える、トランスクリプトを読む、操作を引き継ぐ。あなたのネットワーク上のブラウザー、携帯、デスクトップのどれからでもできます。

プライバシーとセキュリティ

あなたのマシン。あなたのネットワーク。あなたのデータ。

サーバーの状態は、それを動かしているマシンに留まります。セッションの内容は、あなたが選んだ ネットワーク経由で認証済みのクライアントにだけ送られます。

中継サービスなし

通信経路に cosyncing が運用するサービスは存在しません。分析や広告のテレメトリーもありません。任意の連携機能は、あなたが選んだサービスにだけ接続します。

いつでも失効できる

cosyncing devices list でペアリング済みの端末を一覧表示し、devices revoke <id> で 1 台を失効させます。

質問を見逃さない

すべての質問を 1 つの受信箱に

エージェントがあなたを必要としたら、通知の受信箱に届きます。そのとき手元にある端末から答えられます。

  • 権限リクエスト はコマンドの文脈つきで届きます。ワンタップで承認するか、閉じられます。
  • エージェントからの質問 はセッションに接続したままなので、答えはエージェントが待っている場所に届きます。
  • 完了した実行 — 長い処理は、待っているときだけでなく、終わったときにも知らせます。
  • 複数サーバー対応 — ペアリング済みのすべてのサーバーが同じ一覧に集まります。
