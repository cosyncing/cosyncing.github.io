安装

安装 cosyncing 0.1.0

首个受支持的 npm 发行版现已发布。请先安装 Bun 1.3.8 或更高版本； cosyncing 的 npm 包不内置 Bun 运行时。 

# 需要 Bun 1.3.8 或更高版本
$ npm install --global cosyncing
$ cosyncing setup
$ cosyncing pair

Features

每个会话，触手可及

Broker 在智能体本就在运行的地方观察它们，并提供一个客户端来展示每个会话 —— 按项目归组，附带对话记录、diff、命令和提问。

所有项目，一个空间

做你自己所有智能体的总指挥 —— 工作中、待输入和空闲状态一目了然。打开会话即可阅读对话记录、检查 diff，并实时跟随每一次工具调用。

通知收件箱

权限请求、智能体提问和运行完成通知，汇聚在同一个跨多 Broker 的收件箱里。

双向同步

从应用发送提示词，终端照常运转 —— Codex、OpenCode、Pi 会话两端始终保持一致。Claude Code 会话在接管前保持只读。

显式配对

设备通过一张五分钟有效、仅限一次的二维码获得授权 —— 可在 CLI 中列出和撤销。

定时消息

把提示词安排在指定时间送达 —— 智能体会准时收到并开始工作。

How it works

三步搞定，无需账号

1

运行 Broker

cosyncing setup 会清楚展示它将改动的内容，然后要么整体应用、要么完全不动。

2

配对设备

cosyncing pair 打印一张仅限一次的二维码。用任意客户端扫码，即可授权该设备。

3

持续前行

回应提问、阅读对话记录，或直接接管 —— 在你网络里的浏览器、手机或桌面上。

Privacy & security

你的机器。你的网络。你的数据。

Broker 状态留在运行它的那台机器上。会话内容只会通过你选择的网络发送给已认证的客户端。

没有托管中继

连接路径中没有 cosyncing 运营的服务，也不含分析或广告遥测。可选集成只会联系你选择的服务。

默认即可撤销

cosyncing devices list 列出已配对设备；devices revoke <id> 撤销指定设备。

Never miss a prompt

每个提问，一个收件箱

当智能体需要你时，就会出现在通知收件箱里。用手边的任何一台设备回答即可。

  • 权限请求附带完整的命令上下文 —— 一次点按即可批准或驳回。
  • 智能体提问期间会话保持连接，回答直接落在智能体等待的地方。
  • 运行完成 —— 长任务跑完时同样会通知你，而不只是等待你回应时。
  • 多 Broker —— 每个已配对的 Broker 都汇报到同一个列表。
